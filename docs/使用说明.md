# 使用说明

## 单份简历分析

1. 打开前端页面。
2. 进入“单份分析”。
3. 上传 `.docx` 或 `.pdf` 简历。
4. 填写目标岗位或岗位 JD。
5. 点击“开始分析”。
6. 系统默认优先调用 DeepSeek 生成诊断和建议；如果未配置 API Key、无网络或接口异常，会自动回退到离线规则分析。
7. 在“报告详情”查看评分、图表、问题诊断和修改建议。
8. 下载 Word 或 PDF 报告。

## 批量简历分析

1. 进入“批量分析”。
2. 上传 `.zip` 文件。
3. 系统会筛选 ZIP 中的 `.docx` 和 `.pdf` 文件。
4. 每份简历独立分析。
5. 页面显示成功数量、失败数量和每份简历的摘要。

## 历史记录

进入“历史记录”查看过去的分析结果。可以查看详情，也可以删除记录。删除时系统会同步清理对应文件。
