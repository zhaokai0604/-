# 提示词对比实验执行单（替代高风险微调主叙事）

> 在 A 池裁决完成前，本实验只用**合成/锁定脱敏样例**做回归；裁决稳定后再从黄金标签抽 Few-shot，测试池样本永不进示例。

## 一、三组对照（固定）

| 组 | 内容 | 禁止 |
|---|---|---|
| P0 基础 | 任务说明 + JSON Schema | 无评分口径、无禁编造 |
| P1 规范 | P0 + 评分口径 + 禁止编造 + unknown 规则 | 无真实简历示例 |
| P2 Few-shot | P1 + 8～15 条 A 池代表例 | 测试池 / B 池边界样例进 Prompt |

每组同一批输入跑 2 次（稳定性），记录取平均或“两次一致率”。

## 二、必记指标（不要 Spearman）

| 指标 | 通过线（建议） |
|---|---|
| JSON 可解析率 | = 100% |
| 必填字段完整率 | ≥ 95% |
| 无证据时 unknown/待补充命中 | 对照样例全中 |
| 编造学校/经历/技能/量化 | = 0 |
| 两次结构一致率 | ≥ 90% |
| 建议能对应证据缺口 | 人工抽检通过 |

若 P2 只在示例同源提升、在独立测试池下降 → **判定过拟合，线上退回 P1**，不做微调。

## 三、样例分层

- 开发回归：合成护栏样例（学历不符、无证据等）
- 验证：A 池裁决后代表例（选 Prompt 版本）
- 测试：冻结独立池，终验收只跑一次

## 四、记录表（复制填）

| 组 | JSON合法 | 字段完整 | unknown正确 | 零编造 | 两次一致 | 测试池是否下降 | 结论 |
|---|---|---|---|---|---|---|---|
| P0 | 基线 | — | 弱 | 风险高 | — | — | 仅开发对照 |
| P1 | 目标 100% | ≥95% | 护栏样例全中 | 强制 | ≥90% | — | **线上默认** |
| P2 | 同 P1 | 同 P1 | 同 P1 | 同 P1 | 同 P1 | 若下降则弃用 | 示例池=裁决后代表例，测试池禁入 |

## 五、赛前冻结结论

- 线上主路径：**规范 Prompt（P1）**，不把小样本微调当验收依据。  
- Few-shot（P2）仅可从裁决后 A 池代表例挑选；独立测试池不得进 Prompt。  
- 若赛前来不及跑满 P0/P2 表，答辩只陈述「采用结构化提示词 + 禁止编造 + unknown 规则」，不编造未跑的数字。

最终对外一句话：

> 未将小样本真实简历用于基础模型微调验收；采用冻结语义能力 + 结构化提示词，以 JSON 合法率、禁编造与 unknown 安全为主指标。
