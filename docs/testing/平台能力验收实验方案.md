# 简析智评平台能力验收实验方案

## 一、实验边界

本方案不把已经参与调参、融合权重拟合、Prompt 设计或模型训练的数据当作平台验收数据。

- 真实简历数据：只做本地离线可接入性、解析边界和人工抽样复核，不写入平台演示数据，不作为线上业务数据。
- 平台验收数据：使用固定的脱敏/合成/授权样例，样例版本锁定后只读，不能在测试过程中修改答案。
- 历史 61 条岗位弱标注集、alpha 融合实验和 SBERT 微调结果：保留为探索性附录，不进入平台主指标。
- 测试集：不参与规则修改、Prompt 示例选择、阈值选择或报告口径调整，最终验收前只运行一次。

## 二、实验目标

平台最终要证明的是“能稳定处理、结果可解释、异常不误判、输出可交付”，而不是证明小样本微调后的模型分数最高。

## 三、五类主实验

| 实验 | 固定输入 | 主要指标 | 结论用途 |
|---|---|---|---|
| 功能基准 | 版本锁定的 DOCX/PDF/文本样例 | 文件接入率、解析成功率、分析成功率、报告生成率 | 证明主流程能跑通 |
| 解析鲁棒性 | 清晰排版、表格、双栏、图片文字、OCR 噪声样例 | 文本可读率、板块识别 P/R/F1、低质量告警命中率 | 说明能力边界 |
| 护栏安全性 | 学历不符、经验不足、无学历证据、岗位为空等合成对照样例 | 违规识别率、误拦截率、unknown 安全处理率 | 证明规则不会乱拦截 |
| 提示词回归 | 训练/示例池与独立测试池 | JSON 合法率、字段完整率、禁止编造命中率、建议可执行率 | 验证 Prompt 不退化 |
| 性能稳定性 | 固定小、中、大文本和固定并发级别 | P50/P95/P99、成功率、超时率、重复结果一致性 | 证明平台可用性 |

## 四、提示词工程实验

只从 A 池中选择 8～15 条代表性脱敏样例制作 Few-shot Prompt，覆盖教育、实习、项目、技能、复杂版式和缺失证据。B 池只做边界验证，测试池不得进入 Prompt。

至少比较三组：

1. 基础 Prompt：无示例，仅有任务和 JSON Schema；
2. 规范 Prompt：增加评分口径、禁止编造和低置信度规则；
3. Few-shot Prompt：在规范 Prompt 上增加 A 池代表样例。

比较重点不是 Spearman，而是：

- 返回 JSON 可解析率；
- 必填字段完整率；
- 无证据时是否正确输出 unknown 或待补充；
- 是否编造学校、经历、技能和量化成果；
- 相同输入重复运行是否保持结构稳定；
- 建议是否能对应简历中的证据缺口。

如果 Few-shot 只在 A 池提升、在独立测试池下降，则判定为示例过拟合，退回规范 Prompt，不进行模型微调。

## 五、实验数据分层

- 规则回归集：人工编写的固定样例，允许用于开发和回归，不作为真实用户效果证明。
- 验证集：用于选择 Prompt 版本、阈值和告警等级。
- 测试集：冻结后只在最终验收运行一次。
- 真实简历离线集：用于接入率和人工抽样复核，不能直接复制到平台数据库、演示数据或线上训练流程。

## 六、指标分层（验收报告必须分栏）

| 栏 | 指标 | 结论写法 |
|---|---|---|
| 成功率 | 文件接入、分析完成、报告生成 | 只证明链路可交付 |
| 可读性 | 无 OCR / 有 OCR 文本可读率 | 只证明复杂 PDF 需要 OCR |
| 分析可信度 | 板块抽检、护栏命中、unknown、可信度告警 | 才谈“结果是否可采信” |

A 池前 15 已第三方裁决，可引用 `data/eval/real_parse_metrics_adjudicated_common15.json` 的板块 micro F1（约 0.98），**必须**写清「真实脱敏、裁决后、板块是否非空」。OCR 可读率与板块 F1 分栏。Prompt 见《提示词对比实验执行单.md》；冻结见《赛前收口完成.md》。

## 七、推荐验收表述

> 本项目没有使用小规模真实简历强行微调基础模型，而是采用冻结语义能力、结构化提示词、岗位知识库、规则护栏和证据解释的组合方案。实验重点从模型拟合分数转向平台可用性、解析鲁棒性、异常安全性、输出稳定性和端到端性能。成功率、文本可读率与分析可信度分栏报告，不以单一数字概括质量。

## 八、禁止事项

- 不把同一数据既用于选择 Prompt 又用于最终测试。
- 不把历史 61 条弱标注集的分数写成平台准确率。
- 不把 OCR 文本可读率写成解析字段准确率。
- 不把分析成功率写成打分或板块准确率。
- 不把真实简历直接写入数据库、Git、Prompt 或对外报告。
- 不为获得更高指标反复修改测试集标签。
- 不把裁决前双人初标或未裁决标签当作真实 F1；不做微调主叙事。
