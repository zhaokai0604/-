## 1. 附件要解决什么问题

简历与岗位描述常出现**同义表达、跨领域负例、关键词不全但语义相关**等情况。纯规则关键词覆盖不足，纯大模型又难离线、难解释。

本附件对应的技术方案（**探索路径，非平台主验收**）：

1. 在中文句向量基座上，用弱标注「简历–岗位」对做 **SBERT 双塔微调**  
2. 再拟合 **规则分 ⊕ 语义分** 的融合权重 α  
3. 可选推理：`Final ≈ α · Rule + (1-α) · Semantic`（当前探索权重 α≈0.37）

平台线上主叙事仍以规则可解释、岗位知识库、提示词护栏与分层可信度为主；本附件仅证明「做过可复现语义增强实验」。

## 3. 训练配置摘要

来源：`data/models/sbert-resume-match/train_meta.json`

| 项 | 值 |
|----|-----|
| 基座模型 | `shibing624/text2vec-base-chinese` |
| 任务形式 | 简历文本 ↔ 岗位/JD 文本，双塔句向量 |
| 损失函数 | `CosineSimilarityLoss` |
| 标签映射 | `label / 5.0`（1–5 分归一到 0–1） |
| Epochs | 2 |
| Batch size | 8 |
| 训练对数 | 61（与评测集同源弱标注） |
| 默认输出目录 | `data/models/experiments/sbert-resume-match-train/` |
| 融合权重 α | ≈0.37（`match_blender.json`） |

说明：样本为**脱敏合成/弱标注**简历–岗位对，用于工程验证与排序一致性提升，答辩时注明「本地工程消融」。

## 4. 复现步骤（Windows / 项目 venv）

```bash
cd backend

# 0）建议使用项目虚拟环境，并安装语义依赖
.\.venv\Scripts\python.exe -m pip install -r requirements-semantic.txt

# 1）构建/确认评测集
.\.venv\Scripts\python.exe scripts\build_match_eval_set.py

# 2）微调双塔（需可正常 import torch）
.\.venv\Scripts\python.exe scripts\train_sbert.py

# 3）拟合融合 α 与 IDF
.\.venv\Scripts\python.exe scripts\train_biencoder.py

# 4）消融评测
.\.venv\Scripts\python.exe scripts\eval_match_baseline.py
```

可选参数（`train_sbert.py`）：

```bash
.\.venv\Scripts\python.exe scripts\train_sbert.py --epochs 2 --batch-size 8 --base-model shibing624/text2vec-base-chinese
```

国内下载基座如较慢，可先设置镜像再训练：

```bash
set HF_ENDPOINT=https://hf-mirror.com
```

线上启用微调权重（仅完成独立留出验证后；项目根目录 `.env`，**勿提交**）：

```env
USE_SEMANTIC_MATCH=true
USE_SEMANTIC_MODEL=true
SEMANTIC_MODEL_PATH=../data/models/experiments/sbert-resume-match-train
# 只有独立验证后的融合器才允许显式配置
# SEMANTIC_BLENDER_PATH=../data/models/experiments/match-train/match_blender.json
```

## 5. 本地消融结果（仅附件复现用，禁止主 PPT）

评测脚本：`backend/scripts/eval_match_baseline.py`  
数据：`data/eval/match_cases.json`（61 条弱标注；样本曾参与调参 / α 拟合，**非独立测试集**）  
指标：Spearman(弱标注 label, 系统得分)

| 通道 | Spearman |
|------|----------|
| Rule-only | 0.6543 |
| Semantic（微调双塔 SBERT） | 0.9056 |
| Fused（规则+语义，α≈0.37） | 0.8919 |
| Fused − Rule | +0.2376 |

对照（未开 SBERT、仅分词+同义时）：Fused − Rule 约 +0.14。  

**允许的说法（仅附录页 / 被追问时）：**

> 在同一批弱标注排序任务上做过规则 / 语义 / 融合对照，数字可复现；因测试隔离不足，**不作为平台泛化验收结论**。平台主结论见功能、可读性、护栏与裁决后板块 F1。

## 6. 与系统主链路的关系

```text
简历正文 + 目标岗位/JD
    → 规则匹配（关键词 / 岗位画像 / 分节加权）
    → 语义匹配（本附件微调双塔，可选）
    → α 融合得分
    → 写入六维评分中的「岗位语义匹配」
    → 证据片段、critical/minor 缺口、优化稿建议
```

原则：

- **无微调权重时**：系统仍可离线运行（规则 + 分词语义基线）  
- **有微调权重时**：同义表达与跨岗负例排序更稳  
- 大模型（如 DeepSeek）仅作可选润色，**不替代**本匹配模型
