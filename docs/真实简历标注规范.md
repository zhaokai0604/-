# 真实简历评测标注规范

## 数据边界

- 只使用 `data/anonymized_real_resumes/` 或 `data/resume_pools/` 中的脱敏文本。
- 原始 DOCX/PDF 不进入评测 JSON、训练集或提交附件。
- C 池只用于演示；B 池用于边界验证；A 池用于解析评测。
- 不使用大模型自动生成板块标签或岗位匹配标签。

## A 池板块标签

`gold_sections` 只填写文本中确实存在内容的板块：

`basic_info`、`education`、`internship`、`projects`、`campus`、`skills`、`awards`、`summary`

标题缺失但正文语义明确时仍标记对应板块；只有无法判断时不标记。

## 交叉标注

两名成员独立标注同一批样本，记录 `annotator_a`、`annotator_b` 和 `adjudicated_by`。分歧样本由第三名成员裁决，不直接覆盖原始标注。

裁决细则、字段边界与本轮优先级见 [`docs/testing/A池分歧裁决规则与清单.md`](testing/A池分歧裁决规则与清单.md)。工作表由 `backend/scripts/build_adjudication_worksheet.py` 从分歧 JSON 生成。
## 岗位匹配标签

真实岗位匹配集单独保存，不与现有 61 条合成基准集合并。每条记录包含脱敏简历、人工整理 JD、岗位类别、1-5 匹配等级和标注说明。训练/测试按人员或岗位分组切分，禁止同一文本变体跨集合。

## 评测命令

```powershell
cd backend
.\.venv\Scripts\python.exe scripts\eval_real_annotations.py `
  --input ..\data\eval\real_parse_annotations.json `
  --output ..\data\eval\real_parse_metrics.json
```

报告中的 F1 只能表述为“真实脱敏样本的板块识别 F1”，不得表述为字段级抽取准确率或整体简历解析准确率。
