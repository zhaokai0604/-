# UI 美化方向：数据驾驶舱型

本轮前端 UI 改造采用“数据驾驶舱型”方向，目标是让简历评价智能体在比赛展示时更快传达三个核心能力：简历解析、量化评分、岗位匹配与报告导出。

## 设计目标

- 首屏呈现为专业分析控制台，而不是普通表单页面。
- 保留单份分析、批量分析、报告详情、历史记录、配置五个功能入口。
- 强化“离线可运行”“本地数据安全”“可导出报告”等比赛答辩重点。
- 修复当前前端中文乱码问题，保证展示文案清楚可信。
- 使用统一的按钮、表单、标签、表格和图表视觉语言。

## 页面结构

- 左侧导航：显示产品名称、当前分析模式、功能入口。
- 顶部概览：根据当前页面显示任务标题、工程状态、离线模式标签。
- 单份分析页：左侧上传与岗位输入，右侧展示流程、隐私安全和评分维度。
- 批量分析页：支持 ZIP 上传，结果区域展示成功数量、总文件数和单份摘要。
- 报告详情页：总分卡片、文件信息、导出入口、分析来源、图表、诊断建议、岗位匹配。
- 历史记录页：表格化查看、打开报告、删除历史。
- 配置页：DeepSeek 增强开关、默认用户和数据安全说明。

## 视觉规则

- 主色使用深蓝绿，辅色使用青绿色，适合数据分析工具而不显得浮夸。
- 背景使用冷灰白，内容面板使用白色，保留清晰边界。
- 卡片圆角控制在 8px 左右，不使用夸张圆角和装饰性渐变文字。
- 图标统一使用 lucide-vue-next。
- 移动端折叠为单列，导航变为横向网格。

## 验收标准

- `npm run build` 能通过。
- 浏览器打开 `http://127.0.0.1:5173` 后中文正常显示。
- 页面入口包含：单份分析、批量分析、报告详情、历史记录、配置。
- 单份上传页和报告详情页在视觉上具备比赛展示感。
- 图表和下载按钮在报告详情中布局清楚，不遮挡、不溢出。
