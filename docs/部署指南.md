## 3. 方式 A：双击启动（推荐评委使用）

这是**最简单**的启动方式，适合比赛现场、评审电脑快速体验。

### 3.1 操作步骤

```
① 解压作品包 → 进入文件夹「简历分析V2.0」
② 双击 start_dev.bat
③ 等待弹出 2 个黑色窗口（不要关闭）
④ 浏览器自动打开；若未打开，请手动访问 http://127.0.0.1:5174
```

### 3.2 第一次启动会发生什么

脚本会自动完成以下工作（请耐心等待 1～3 分钟）：

1. 若没有配置文件，会从 `.env.example` 复制生成 `.env`
2. 创建 Python 虚拟环境并安装后端依赖
3. 创建本地数据库文件 `data/resume_ai_dev.db`
4. 自动创建 **管理员账号**（见 [第 6 节](#6-演示账号说明)）
5. 安装前端依赖并启动网页服务

### 3.3 如何确认启动成功

在浏览器访问：http://127.0.0.1:8000/api/health

若看到类似下面的文字，说明后端正常：

```json
{
  "status": "ok",
  "database": "ok",
  "redis": "disabled",
  "worker": "background_tasks"
}
```

再访问：http://127.0.0.1:5174 — 应能看到系统首页。

### 3.4 如何关闭

分别关闭标题为 **Resume AI Backend** 和 **Resume AI Frontend** 的两个命令行窗口即可。

### 3.5 分别启动（可选）

若只需单独调试某一端：

| 脚本 | 作用 |
|------|------|
| `start_backend.bat` | 只启动后端（API） |
| `start_frontend.bat` | 只启动网页（需后端已运行） |

## 4. 配置说明（评委必读）

本节说明：**评委到底要不要配、配什么、怎么改**。不必懂编程，会用记事本打开文件即可。

### 4.1 一句话结论

| 启动方式 | 评委要不要自己配置？ | 说明 |
|----------|----------------------|------|
| **双击 `start_dev.bat`** | **一般不用** | 首次启动会自动从模板复制配置，演示账号、离线模式均已写好 |
| **Docker 启动** | **只需 1 步** | 需先执行 `copy .env.example .env`，模板里已填好演示值，通常不用改内容 |
| **想改管理员密码 / 开 AI** | **可选** | 用记事本编辑 `.env`，改完重启即可 |

> 参赛作品包中的 **`.env.example`** 就是「配置模板」，已预置评委演示所需项。  
> 实际生效的是同目录下的 **`.env`** 文件（首次启动时自动生成）。

### 4.2 配置文件在哪里

```text
简历分析V2.0/
├── .env.example    ← 作品包自带【配置模板】，已写好演示默认值（可提交赛事）
└── .env            ← 首次启动后自动生成【实际配置】，含本机密码等（勿提交公开）
```

**如何打开编辑**：在项目文件夹中找到 `.env`，右键 → **打开方式** → **记事本**。

若看不到 `.env`：在资源管理器「查看」中勾选 **「隐藏的项目」**；或首次运行一次 `start_dev.bat` 后会自动创建。

### 4.3 已预置好的配置（评委默认不用改）

以下项在 `.env.example` 中**已经填好**，双击启动或复制后可直接使用：

| 配置项 | 预置值 | 作用（通俗说明） |
|--------|--------|------------------|
| `ADMIN_USERNAME` | `admin` | 管理员登录用户名 |
| `ADMIN_PASSWORD` | `ChangeThisDemoPassword1` | 管理员登录密码，建议首次使用前修改 |
| `ADMIN_DISPLAY_NAME` | `系统管理员` | 管理员在界面上的显示名 |
| `ALLOW_REGISTER` | `true` | 允许新用户自助注册 |
| `DEEPSEEK_API_KEY` | （空） | 不填 = 自动离线分析，**不影响演示** |
| `USE_CELERY` | `false` | 本地双击模式不用 Redis，更简单 |
| `MAX_UPLOAD_SIZE_MB` | `20` | 单份简历最大 20 MB |
| `MAX_ZIP_TOTAL_SIZE_MB` | `120` | 批量 ZIP 最大 120 MB |
| `SESSION_COOKIE_SECURE` | `false` | 本地 http 访问，无需 HTTPS |

**因此：大多数评委解压 → 双击启动 → 即可体验，无需手工改任何配置。**

### 4.4 评委可选修改的配置

若有以下需求，再编辑 `.env`（改完后**关闭并重新启动**系统）：

#### ① 修改管理员密码

打开 `.env`，找到并修改：

```env
ADMIN_PASSWORD=您的新密码
```

要求：至少 8 位，须同时包含**字母**和**数字**。

若之前已经启动过、旧密码仍生效，请：

1. 关闭后端窗口  
2. 删除 `data/resume_ai_dev.db`  
3. 重新运行 `start_dev.bat`

#### ② 开启 AI 增强（可选，非必须）

若有 DeepSeek API Key，且希望演示「AI 改写更自然」的效果：

```env
DEEPSEEK_API_KEY=sk-您的密钥
```

留空则系统自动使用离线规则分析，**核心功能完整可用**。

也可在网页右上角 **「设置」** 中开关 AI，无需改文件。

#### ③ 关闭用户注册（演示时一般不用关）

```env
ALLOW_REGISTER=false
```

#### ④ 修改上传大小限制

```env
MAX_UPLOAD_SIZE_MB=20
MAX_ZIP_TOTAL_SIZE_MB=120
```

按需要改数字即可（单位：MB）。

## 5. 方式 B：Docker 启动（免装 Python）

适合已安装 Docker Desktop 的评委，无需单独安装 Python 和 Node.js。

> **配置**：Docker 方式需先准备配置文件，详见 [第 4 节](#4-配置说明评委必读)。通常只需复制模板，不必修改内容。

### 5.1 操作步骤

在 PowerShell 或命令提示符中，进入项目目录后执行：

```powershell
copy .env.example .env
docker compose up -d --build
```

首次执行需要下载镜像，可能需要 **5～15 分钟**，请保持网络畅通。

### 5.2 访问地址

| 页面 | 地址 |
|------|------|
| 系统首页 | http://localhost:5173 |
| 健康检查 | http://localhost:8000/api/health |

### 5.3 常用管理命令

```powershell
docker compose ps          # 查看各服务是否在运行
docker compose logs -f backend   # 查看后端日志
docker compose down        # 停止全部服务
```

### 5.4 中文路径导致构建失败

若 Docker 报错，可尝试：

```powershell
$env:COMPOSE_BAKE = 'false'
$env:DOCKER_BUILDKIT = '0'
docker compose up -d --build
```

## 6. 演示账号说明

### 6.1 账号总览

| 角色 | 用户名 | 密码 | 如何获得 | 适合演示什么 |
|------|--------|------|----------|--------------|
| **游客** | 无需登录 | — | 打开网页直接用 | 上传分析、看报告（最快） |
| **学生** | 自行注册 | 自设（≥8位，含字母数字） | 右上角「注册」 | 历史记录、多版本对比 |
| **管理员** | `admin` | `ChangeThisDemoPassword1` | 首次启动自动创建 | 用户管理、系统配置、审计 |
| **教师** | 任意已注册用户名 | 注册时自设 | 由管理员在后台分配角色 | 班级统计、学生概览 |

> 默认管理员密码写在 `.env.example` 中。正式对外上线前，**必须**在 `.env` 里改成强密码。

### 6.2 管理员登录步骤

1. 打开系统首页
2. 点击右上角 **「登录」**
3. 输入：
   - 用户名：`admin`
   - 密码：`ChangeThisDemoPassword1`
4. 登录成功后，左侧菜单出现 **用户管理 / 岗位模板 / 系统管理**

### 6.3 如何体验教师端

教师账号需要管理员手动分配：

1. 用 `admin` 登录
2. 进入 **「用户管理」**
3. 先注册一个测试学生账号（或选择已有用户）
4. 将该用户的 **角色** 改为 **「教师」**
5. 退出登录，用该测试账号重新登录
6. 左侧出现 **教师看板、班级分析、学生概览**

**重要**：教师端只能看到学生姓名、班级、分数等统计信息，**看不到简历正文**，这是系统的隐私设计。

### 6.4 忘记管理员密码怎么办

1. 关闭正在运行的后端窗口
2. 打开项目根目录下的 `.env` 文件（记事本即可）
3. 修改这一行：`ADMIN_PASSWORD=您的新密码`（须 ≥8 位，含字母和数字）
4. 删除文件 `data/resume_ai_dev.db`（会清空本地演示数据）
5. 重新双击 `start_dev.bat`，系统会按新密码重建管理员

## 8. 推荐体验路径

以下路线约 **10 分钟**，可按答辩时间裁剪：

| 步骤 | 操作 | 向评委说明的要点 |
|------|------|------------------|
| 1 | 游客身份上传 `.docx` 简历 | 无需注册即可使用；支持 Word/PDF |
| 2 | 填写「数据分析师」等目标岗位 | 岗位匹配是核心能力之一 |
| 3 | 查看详情页六维评分与雷达图 | 评分由规则引擎计算，结果稳定可解释 |
| 4 | 查看「匹配证据」「行动建议」 | 不是空泛评语，能对应到简历原文 |
| 5 | 打开「改写预览」 | 有 AI 则更自然；无 AI 自动离线，流程不中断 |
| 6 | 体验「模拟面试」 | 延伸能力：面试准备 |
| 7 | 下载 Word 分析报告 | 可交付的正式报告 |
| 8 | 上传 ZIP 做批量分析 | 适合班级、就业指导场景 |
| 9 | 用 admin 登录看管理后台 | 平台治理：用户、审计、配置 |
| 10 | 切换教师账号看班级统计 | 教师只看元数据，保护学生隐私 |

## 9. 各角色能做什么

## 10. 关于 AI：有网/没网都能演示

本系统的设计理念是：**规则分析是底座，AI 是可选增强**。

| 场景 | 系统表现 | 能否完成演示 |
|------|----------|--------------|
| 未配置 DeepSeek API Key | 使用离线规则分析 | ✅ 可以 |
| 无外网 | 自动离线 | ✅ 可以 |
| API 调用失败 | 自动回退，页面提示 offline_fallback | ✅ 可以 |
| 已配置 Key 且网络正常 | AI 增强诊断与改写 | ✅ 可以，效果更好 |

因此，**评委无需为我们配置 API Key，也不依赖外网**，即可完成全部核心功能演示。

若需完全本地、不调用任何外部服务，可在页面 **「设置」** 中关闭 AI 增强。

## 11. 数据存在哪里、是否安全

### 11.1 文件存放位置

| 内容 | 存放文件夹 | 说明 |
|------|------------|------|
| 上传的简历原件 | `data/uploads/` | 本机磁盘 |
| 分析产生的报告 | `data/reports/` | Word / PDF |
| 本地数据库 | `data/resume_ai_dev.db` | 双击启动模式下的账号与记录 |

### 11.2 隐私保护要点

- 不同登录用户的数据相互隔离
- 游客数据按浏览器会话隔离
- 教师端 **仅展示统计元数据**，不展示简历正文
- 删除历史记录时，会同步删除对应文件
- 仅在配置 DeepSeek 且用户开启 AI 时，才会把简历文本发往外部 API

详细说明见 [`docs/数据安全说明.md`](数据安全说明.md)。

## 12. 常见问题与解决办法

### 问题 1：双击 start_dev.bat 后窗口一闪就关

**可能原因**：未安装 Python，或安装时未勾选 Add to PATH。

**解决办法**：

1. 打开 PowerShell，输入 `py -3.12 --version` 检查是否安装成功
2. 若报错，请重新安装 Python 3.12 并勾选 PATH
3. 在项目文件夹地址栏输入 `cmd` 回车，再输入 `start_dev.bat`，可看到具体报错

---

### 问题 2：网页打不开 / 一直转圈

**解决办法**：

1. 确认两个黑色窗口都还在运行
2. 手动访问 http://127.0.0.1:5174
3. 首次启动前端编译约需 30 秒～1 分钟，请稍等
4. 访问 http://127.0.0.1:8000/api/health 检查后端是否正常

---

### 问题 3：管理员 admin 登录失败

**解决办法**：

1. 确认密码为 `ChangeThisDemoPassword1`（注意大小写）
2. 若曾修改过 `.env` 中的 `ADMIN_PASSWORD`，以 `.env` 中为准
3. 仍不行：删除 `data/resume_ai_dev.db`，重新运行 `start_dev.bat`

---

### 问题 4：上传简历后报错

**解决办法**：

1. 优先使用 `.docx`（Word）格式演示
2. 单文件不超过 20 MB；ZIP 总量不超过 120 MB
3. 老版 `.doc` 请用 Word「另存为」→ `.docx`
4. 扫描版 PDF 识别较弱，建议用文字版 PDF 或 Word

---

### 问题 5：PDF 报告中文乱码

**解决办法**：确认项目内存在字体文件 `assets/fonts/NotoSansSC-Regular.ttf`，部署时不要漏掉 `assets` 文件夹。

---

### 问题 6：Docker 启动很慢或失败

**解决办法**：

1. 确认 Docker Desktop 已启动（托盘图标正常）
2. 首次需下载镜像，请耐心等待
3. 中文路径问题见 [5.4 节](#54-中文路径导致构建失败)
4. 查看日志：`docker compose logs -f backend`

---

### 问题 7：如何体验教师端

见 [6.3 节](#63-如何体验教师端)：需管理员先将某用户角色改为「教师」。

```
浏览器（Vue 3 网页）
        ↓
   后端 API（Python FastAPI）
        ↓
   ┌────┴────┐
```

| SQLite / MySQL | 存储用户与分析记录 |
| Redis + Celery | Docker 模式下处理批量异步任务（可选） |
| DeepSeek API | 可选 AI 增强，非必需 |
