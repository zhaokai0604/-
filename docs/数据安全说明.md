# 数据安全说明

系统默认优先使用 DeepSeek 分析，会在配置了 `DEEPSEEK_API_KEY` 且前端开关开启时，把简历文本和规则评分结果发送给配置的 DeepSeek API。若需要完全本地处理，可在前端“配置”页关闭 DeepSeek。

## 本地存储

- 原始上传文件：`data/uploads/`
- ZIP 解压文件：`data/extracted/`
- 导出报告：`data/reports/`

## 外部 API

DeepSeek 分析默认开启，但只有同时满足以下条件才会真正调用外部 API：

1. `.env` 中配置了 `DEEPSEEK_API_KEY`。
2. 用户在前端保持“优先使用 DeepSeek 分析”开启。

如果未配置 API Key、网络不可用、接口超时或 API 返回异常，系统会自动回退到本地规则分析，并把记录标记为 `offline_fallback`。

## 删除机制

删除历史记录时，系统会同步删除：

- 原始简历文件
- 解压出的临时文件
- Word 报告
- PDF 报告

## ZIP 安全

系统会拒绝包含路径穿越的 ZIP 文件，并限制 ZIP 解压后的总大小。
