## 0. 简析智评三擎架构（必贴）

> 简析智评采用「**语义理解、证据护航、生成交付**」三擎协同架构，形成从简历解析、岗位匹配、风险校验到优化交付的完整服务链路。

| 现有能力 | 包装名称 | 职责 |
|----------|----------|------|
| 双塔 SBERT（本地） | **语义理解引擎** | 理解简历与岗位要求的语义关系，完成岗位匹配排序 |
| 规则 / 分词基线（本地算法） | **证据护航引擎** | 学历硬约束、关键词核验、风险拦截、结果解释；**不是深度模型** |
| DeepSeek 等（可选云端） | **生成交付引擎** | 把诊断转化为优化稿、建议、报告与模拟面试；**无 Key 时本地模板回退** |

```text
语义理解引擎：判断「简历和岗位是否匹配」
        ↓
证据护航引擎：判断「结论有没有依据、是否触发硬约束」
        ↓
生成交付引擎：转化为优化稿、报告和训练建议
```

口径提醒：核心名称叫三擎，**不要叫「DeepSeek 引擎」**——DeepSeek 只是生成交付引擎的可选云端实现。语义理解引擎的微调数字不作平台准确率（见附录）。

## 0.1 指标三层（评委一问就答）

| 层 | 可以说 | 不能说成 |
|----|--------|----------|
| L1 链路 | 59 份分析成功率 **100%** | 解析准、打分准 |
| L2 可读 | 无 OCR 可读率 **≈55.9%** → 必须开 OCR；开 OCR 后 PDF 可读 | 板块识别准确率 |
| L3 可信 | A 池前 15 **已裁决**；板块 micro F1 **0.98**（P0.97/R0.99） | 字段级准确率、全库泛化、SBERT 主结论 |

一句话：成功率证明能跑；可读率证明要 OCR；F1 是裁决后脱敏样本的板块识别，薄弱主要在项目边界——平台用告警与封顶，不虚高分。

双人初标 `gold_sections` 一致率曾约 33% → 已按规则第三方裁决并落盘；证据见 `A池裁决工作表.json` 与 `real_parse_metrics_adjudicated_common15.json`。

## 2. 五条演示话术（各 15 秒）

1. **优化稿交付**：不只给建议，而是在初稿上打磨出可下载完整优化稿；不足处标【待补充】，不编造经历。  
2. **实时解析流**：上传后 SSE 推送真实中间事件（阅读行、命中关键词、低信噪比、评分），done 即落库。  
3. **初稿 ↔ 优化稿 Diff**：左右对照 + 版本时光机六维 Δ 分，改前改后肉眼可见。  
4. **低信噪比纠偏**：经历相关但证据弱时强制扣分——宁愿信数据，不信散文。  
5. **三擎协同**：语义理解做匹配排序 → 证据护航做硬约束与解释 → 生成交付出优化稿 / 报告 / 面试。

## 4. 对标一句 + 专利边界一句

**对标**：多数竞品全靠 LLM 或纯向量；我们是「简析智评三擎」——语义理解 + 证据护航 + 生成交付，服务高校就业数据治理闭环。

**专利边界**：本赛题主叙事不绑定运维向「AI Agent 多级安全门控」专利；若被问及，仅答「团队在 Agent 工具调用安全方向另有专利布局」，不展开权利要求细节。
