# 简历评价智能体

> **参赛说明文档** — 本文介绍系统功能、体验方式与账号信息。无需编程基础，按步骤操作即可在本机打开并体验完整流程。

---

## 一、项目是什么？

**简历评价智能体** 是一套面向高校场景的简历分析与岗位匹配平台，帮助学生：

- 上传 Word / PDF 简历，获得 **六维评分** 与 **岗位匹配分析**
- 查看 **诊断建议**、**改写示例**、**面试题** 与 **分析报告**
- 支持 **批量分析**（ZIP 压缩包）、**历史记录**、**版本对比**

同时支持 **教师端** 查看班级统计（只看汇总数据，不看简历正文），以及 **管理端** 进行用户与系统管理。

**亮点**：系统以本地规则分析为核心，保证结果稳定可解释；可选接入 DeepSeek 大模型增强表达。**未配置 AI 或网络不通时，会自动切换到离线模式，不影响演示。**

## 二、 3 分钟快速体验

### 第 1 步：准备电脑环境

| 要求 | 说明 |
|------|------|
| 操作系统 | Windows 10 / 11（推荐） |
| Python | 3.10、3.11 或 3.12（[下载地址](https://www.python.org/downloads/)，安装时勾选 **Add to PATH**） |
| Node.js | 18 或以上（[下载地址](https://nodejs.org/)） |
| 浏览器 | Chrome、Edge 等现代浏览器 |

> 若已安装 **Docker Desktop**，也可跳过 Python/Node，直接看 [第五节 Docker 方式](#五可选docker-一键启动)。

### 第 2 步：启动系统

1. 解压参赛作品压缩包，进入项目文件夹 `简历分析V2.0`
2. **双击** `start_dev.bat`
3. 等待弹出两个黑色窗口（后端、前端），并自动打开浏览器

若浏览器未自动打开，请手动访问：

| 页面 | 地址 |
|------|------|
| **系统首页（请打开这个）** | http://127.0.0.1:5174 |
| 后端健康检查（可选） | http://127.0.0.1:8000/api/health |

### 第 3 步：上传简历体验

1. 打开首页后，可 **直接以游客身份** 使用，无需登录
2. 点击左侧 **「单份分析」**
3. 上传一份 `.docx` 或 `.pdf` 简历（可用自备简历或自行准备的样例）
4. 填写 **目标岗位**（如「数据分析师」「产品经理」）
5. 点击分析，等待约 10～30 秒，进入 **简历详情页** 查看评分、建议、匹配证据
6. 可继续体验：**下载 Word 报告**、**AI 改写预览**、**面试准备**、**模拟面试**

**关闭系统**：关闭两个黑色命令行窗口即可。

## 二点五、要不要配置？（评委常问）

| 问题 | 答案 |
|------|------|
| 需要我自己写配置文件吗？ | **一般不用**。双击 `start_dev.bat` 会自动从 `.env.example` 复制生成 `.env` |
| 管理员密码在哪？ | 已写在模板里：`admin` / `ResumeAi@2026` |
| 需要配数据库吗？ | **不用**。本地演示自动用 SQLite，无需安装 MySQL |
| 需要配 AI 密钥吗？ | **不用**。留空即自动离线分析，功能完整 |
| 我想改配置怎么办？ | 用记事本打开项目根目录的 `.env`，改完重启 |

**已预置好的主要配置**

| 配置项 | 预置值 | 说明 |
|--------|--------|------|
| `ADMIN_USERNAME` | `admin` | 管理员用户名 |
| `ADMIN_PASSWORD` | `ResumeAi@2026` | 管理员密码 |
| `ALLOW_REGISTER` | `true` | 允许注册 |
| `DEEPSEEK_API_KEY` | （空） | 不填 = 离线模式 |
| `USE_CELERY` | `false` | 本地模式无需 Redis |

完整配置项说明（共 20+ 项，含每项含义与是否必改）见 **[`docs/部署指南.md` 第 4 节](docs/部署指南.md#4-配置说明评委必读)**。

## 三、演示账号一览

系统提供三种使用方式，评委可按需选择：

### 3.1 游客模式（最简单，推荐先试）

| 项目 | 说明 |
|------|------|
| 是否需要登录 | **否**，打开网页即可使用 |
| 能做什么 | 上传分析、查看结果、下载报告、体验改写与面试功能 |
| 数据范围 | 仅保存在本机，清除浏览器 Cookie 后历史记录不可见 |
| 适合场景 | 快速了解核心分析能力 |

### 3.2 学生账号（注册即用）

| 项目 | 说明 |
|------|------|
| 如何获得 | 点击页面右上角 **「登录 / 注册」** → **注册**，自行设置用户名和密码 |
| 密码要求 | 至少 8 位，须同时包含字母和数字 |
| 能做什么 | 与游客相同，且数据长期保存在账号下，可跨设备登录（同一台部署机器） |
| 适合场景 | 体验完整账号体系、历史记录、多版本对比 |

### 3.3 管理员账号（查看后台管理）

首次启动时，系统会根据配置文件自动创建管理员（见 `.env.example` 模板）。

| 项目 | 内容 |
|------|------|
| **登录用户名** | `admin` |
| **默认密码** | `ResumeAi@2026` |
| **显示名称** | 系统管理员 |

**登录步骤**：

1. 打开 http://127.0.0.1:5174
2. 点击右上角 **「登录」**
3. 输入用户名 `admin`、密码 `ResumeAi@2026`
4. 登录后，左侧菜单会出现 **「用户管理」「岗位模板」「系统管理」**

**管理员可体验**：

- **用户管理**：查看用户列表、启用/禁用账号、重置密码、将某用户设为 **教师** 或 **管理员**
- **岗位模板**：查看全平台岗位画像
- **系统管理**：AI 配置、评分权重、审计日志、存储空间清理

> **说明**：`ResumeAi@2026` 仅为本次参赛演示默认密码。正式部署到公网前，请务必在 `.env` 文件中修改为强密码。

### 3.4 教师账号（需管理员分配）

系统 **不预设教师账号**，需由管理员分配角色后体验：

1. 用 `admin` 登录管理后台
2. 进入 **「用户管理」**
3. 先让一个测试账号 **注册为学生**（或选中已有用户）
4. 将该用户的角色改为 **「教师」**
5. 退出管理员，用该用户登录
6. 左侧会出现 **「教师看板」「班级分析」「学生概览」**

**教师端特点**：只能看到学生账号、班级、分数等 **统计元数据**，**无法查看简历正文**，符合教学场景隐私要求。

## 四、推荐演示路线（约 10 分钟）

## 五、（可选）Docker 一键启动

若评委电脑已安装 **Docker Desktop**，无需单独安装 Python 和 Node.js：

```powershell
# 1. 进入项目目录，复制配置模板
copy .env.example .env

# 2. 启动全部服务（首次需下载镜像，约 5～15 分钟）
docker compose up -d --build
```

启动完成后访问：

| 页面 | 地址 |
|------|------|
| 系统首页 | http://localhost:5173 |
| 健康检查 | http://localhost:8000/api/health |

管理员账号同上：**admin / ResumeAi@2026**

停止服务：

```powershell
docker compose down
```

## 七、关于 AI 与离线模式

| 情况 | 系统行为 |
|------|----------|
| 未配置 DeepSeek API Key | 自动使用 **离线规则分析**，功能完整可用 |
| 已配置 API Key 且网络正常 | 诊断与改写表达更自然，标记为 AI 增强 |
| API 调用失败 | 自动回退离线，页面提示 `offline_fallback`，**不中断流程** |

因此：**评委在无外网、无 API Key 的环境下，仍可完成全部核心演示。**

用户也可在页面 **「设置」** 中关闭 AI 增强，实现完全本地处理。详见 [`docs/数据安全说明.md`](docs/数据安全说明.md)。

## 八、数据与安全说明（简要）

- 简历文件保存在本机 `data/` 目录，不上传至第三方（除非主动开启 AI 并配置 Key）
- 不同用户数据相互隔离；游客按浏览器会话隔离
- 教师只能看到统计数据，不能打开学生简历正文
- 删除历史记录时，会同步清理相关文件

## 九、常见问题（评委版）

**Q：双击 `start_dev.bat` 后闪退？**  
A：请右键「以管理员身份运行」，或在文件夹地址栏输入 `cmd` 回车，再输入 `start_dev.bat` 查看报错。常见原因是未安装 Python 3.12 或未勾选 Add to PATH。

**Q：网页打不开？**  
A：确认两个黑色窗口仍在运行；手动访问 http://127.0.0.1:5174 ；等待前端编译完成（约 30 秒）。

**Q：管理员密码不对？**  
A：默认密码为 `ResumeAi@2026`。若仍无法登录，删除 `data/resume_ai_dev.db` 后重新运行 `start_dev.bat`（会重建数据库与管理员）。

**Q：没有 DeepSeek，能演示吗？**  
A：可以。离线模式是正式支持的能力，不是降级半成品。

**Q：扫描版 PDF 识别不好？**  
A：建议使用 Word（`.docx`）或文字版 PDF 演示。扫描件需额外安装 OCR 组件（见部署指南附录）。

**Q：如何体验教师端？**  
A：先用 `admin` 登录，在「用户管理」中将某用户角色改为「教师」，再用该用户登录。
